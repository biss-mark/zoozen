# Zoozen – Application Single Page (SPA) d'exploration animalière.

### Frontend : 
- React (Hooks, useEffect, Context API), Tailwind CSS pour une interface responsive et moderne.

### Gestion des données & API : 
- Architecture asynchrone robuste (Promise.all) interconnectant 3 APIs distantes : API-Ninjas (caractéristiques techniques), Wikipedia API (extraits textuels) et Unsplash API (galeries photos haute définition).

### Fonctionnalités clés : 
- Recherche dynamique, gestion d'un historique de navigation avec contrôle clavier/modale, mise en favoris personnalisée et suggestions d'animaux par affinité.
